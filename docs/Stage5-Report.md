# Stage 5 Report — Тест индексации лиц на большом наборе

## Цель этапа
Проверить устойчивость и качество пайплайна распознавания лиц на двухшаговом сценарии:
1. Первичное обучение на небольшой папке-эталоне (по 1 фото на человека).
2. Массовая индексация большого архива с вложенными папками.

## Входные данные теста
- Очистка базы лиц перед запуском: выполнена.
- Эталонная папка: `F:\2017\Шарголь\лица`.
- Большая папка: `F:\2017` (рекурсивно).
- Порог face detection: `0.45`.
- Порог автоназначения: `0.55`.

## Наблюдения по логам
### Шаг 1 (эталон)
- Индексация: `7 файлов`, `10 лиц`.
- Ручное подтверждение: `8 лиц`.

### Шаг 2 (большая папка)
- Индексация: `957 файлов`, `919 лиц`.
- Автодоназначение перед ручным подтверждением: `224`.
- Ручное подтверждение: `366`.
- Веб-альбом запущен: `http://localhost:5288`.

## Проблемы/риски, выявленные в этапе
1. Высокий объём `Unknown` на больших сценах (групповые фото, сложные ракурсы, дальние лица).
2. В логах присутствуют кейсы дубликатов по hash (копия и оригинал с одинаковым содержимым).
3. Встречается сценарий `found=yes` + `Existing faces=False` — требует переиндексации конкретной записи.
4. Лог слишком детальный для обычного пользователя, полезен для диагностики, но перегружает итоговое восприятие.

## Изменения, внедрённые по итогам этапа
1. Добавлены итоговые метрики качества в результат индексации:
   - автоназначенные лица,
   - unknown лица,
   - файлы с/без детекций,
   - пропущенные как «без изменений»,
   - переиндексированные из-за отсутствия лиц в найденной по hash записи.
2. Добавлена диагностическая ветка в пайплайн:
   - если запись найдена по hash, но в ней нет лиц, выполняется переиндексация с явной записью в лог.
3. В `MainWindow` добавлена итоговая сводка в лог после завершения индексации.

## Итог этапа
Этап признан успешным: функциональный сценарий «обучение на малом наборе ? массовая индексация» подтверждён. Пайплайн работает стабильно, автоназначение выполняется, веб-альбом стартует.

## Рекомендации на следующий этап
1. Добавить режим кластерного подтверждения `Unknown` (ускорить ручную разметку).
2. Добавить уровень детализации лога (пользовательский/диагностический).
3. Вынести метрики качества в отдельную карточку UI на вкладке `Лица`.
4. Начать отдельный модуль контент-тегов (архитектура/природа/город и т.д.) как следующую фазу перед расширением веб-альбома.
